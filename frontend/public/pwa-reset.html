🔧 PWA Reset

Если PWA не работает, эта страница очистит все Service Workers и кэш.

Ручная очистка (если кнопка не помогла):

  1. Открой DevTools (F12)
  2. Перейди в Application → Service Workers
  3. Нажми Unregister для всех записей
  4. Перейди в Application → Storage
  5. Нажми Clear site data
  6. Обнови страницу с Ctrl+Shift+R
