# AI-Астролог (ai-astrolog1)

AI-сервис персональных и общих гороскопов.

## Стек
- Backend: Laravel 11 + Filament 3
- Frontend: Next.js 14 (PWA)
- БД: PostgreSQL 16 + Redis
- AI: Timeweb AI API
- Натальная карта: Python FastAPI + kerykeion
- Платежи: Т-Банк (рекуррент)
- Рассылки: UniSender, Telegram, MAX

## Документация
- Полное ТЗ: TZ.md
- Переменные окружения: .env.example
